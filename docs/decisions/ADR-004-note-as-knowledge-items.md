# ADR-004: 理解ノート = 知識項目の構成体(独立文書を持たない)

日付: 2026-07-11 / 状態: 採用

## 文脈
§12 理解ノートは「生きた文書」。§20 知識は再配置・検索・比較・AI再利用可能な単位。両方を満たす構造が必要。

## 決定
理解ノートを独立のリッチテキスト文書として保存**しない**。ノート = `note_template`(設定)のセクション順に `knowledge_items` を並べた射影とする。Markdownはエクスポート時に生成する。

## 理由
1. 資料単位のノートと知識単位の横断利用(§22.8)が単一の正本で両立する。二重管理・同期ズレが発生しない。
2. 出所・種別・アンカー・検証状態が項目粒度で必ず保持される(§13)。長文文書内では失われがち。
3. 並べ替え・セクション移動・削除が構造操作になり、AIによる「ノート再整理」も安全に実装できる(項目は不変、配置だけ変える)。

## 代替案
- 単一Markdown文書+埋め込みメタデータ: 人間には自然だが、部分保存・出所追跡・再配置がパースに依存し脆い。却下。

## 帰結
- 「自由に長文を書くノート」体験は、origin=user の知識項目(markdown可)で代替。項目をまたぐ長編考察が書きにくい場合は、将来「自由記述セクション」を note_template に追加検討(open_questions.md)。
