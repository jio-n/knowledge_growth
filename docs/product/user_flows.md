# 主要ユーザーフロー

最終更新: 2026-07-11。画面詳細は ui_spec.md。

## UF-1: 資料登録 → 初読

1. ライブラリで [+ PDF]/[+ URL]/[+ テキスト] → 登録
2. (重複検出時) 既存を開く / 新規登録 を選択
3. 読解画面へ自動遷移。原文が即表示、概要タブでは構造化抽出が進行→完了表示
4. 原文を読み進める。段落hoverの[訳]で日本語訳を原文直下に表示

## UF-2: 分からない箇所を質問 → 理解を保存

1. 原文テキストを選択 → ポップオーバー → [説明](または初学者向け/詳しく/批判的に/応用)
2. 対話タブに回答表示(AI回答バッジ+根拠引用+📍原文リンク)
3. 有用な部分を回答内で選択 → [選択部分を保存]
4. 保存ダイアログ: AI提案の保存先・種別がプリセレクト済 → [保存](計2クリック)
5. ノートタブに項目追加(出所=AI回答、📍付き)

## UF-3: 自分の考察を残す

ノートタブ → 該当セクション [+ メモを追加] → markdown記入 → 保存(出所=自分)

## UF-4: 数ヶ月後の再訪

1. ライブラリ(または横断検索「あの話どこだっけ」)→ 資料を開く
2. 前回のノート・質問履歴・翻訳・ハイライトが全て残っている
3. ノート項目の📍 → 原文該当箇所へジャンプ → 文脈を再確認
4. 未解決セクションを見て次のアクションを決める

## UF-5: 知識の持ち出し

ノートタブ → [Markdownで見る] → プレビュー確認 → ダウンロード(Obsidian等へ)。全退避は /api/export/all.json + data/ フォルダコピー。

## UF-6: 資料間の移動

読解画面ヘッダー [前の資料][次の資料]、または [← ライブラリ] → 別カード。ページをめくる感覚で切替(F-15)。
